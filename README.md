# TP 3 PHP — Suivi des notes

Projet d'exemple pour le TP de Hamza Oubkis.

## Lancer le projet
1. Installer PHP (PHP 8 recommandé).
2. Ouvrir un terminal dans le dossier `tp_php`.
3. Lancer : `php -S localhost:8000`
4. Ouvrir `http://localhost:8000/exo1_bases.php`.

Les fichiers CSV/JSON sont créés automatiquement dans `data/` lors de la saisie ou de l'export. Le dossier `data/` est fourni vide dans l'archive.

## À noter
- Remplacez `Mon établissement` dans `config.php` par le nom de votre établissement.
- Les fichiers sont une base complète d'exercices, à relire et à adapter avant remise.
- Le login est une démonstration pédagogique sans mot de passe ; ne pas utiliser tel quel en production.
